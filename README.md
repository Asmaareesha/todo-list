# To-Do List

A simple command-line to-do list written in Python. It shows a menu where
you can add tasks, view your list, and delete tasks you no longer need.

## How to run it

1. Install Python from python.org
2. Download todo.py
3. Open a terminal in the same folder and run: python todo.py
   (or python3 todo.py on Mac)

## Features

- Add new tasks
- View all tasks in a numbered list
- Delete a task by its number

## What I learned

Using lists, loops, functions like append and pop, f-strings, and
building a menu with if/elif/else statements.

## Planned improvements
